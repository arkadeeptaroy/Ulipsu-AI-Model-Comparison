# Changelog

## 2.0.0

- Rebuilt the static dashboard around an explicit evaluation dataset and decision policy.
- Separated validation, SRT parsing, metrics, review scoring, economics and interface rendering.
- Replaced fixed rankings with reproducible qualification gates and shortlist ordering.
- Added cue-level alignment, Unicode grapheme pacing, critical-error and review-completeness diagnostics.
- Added local JSON and SRT imports, configurable thresholds, cost scenarios and aggregate CSV export.
- Included a clearly labelled synthetic fixture, removing unsupported provider-performance and pricing claims from the active dashboard.
- Removed remote runtime scripts and fonts; added a restrictive content security policy.
- Added a dependency-free test suite, evaluation protocol, product requirements and documented limitations.
- Retained static hosting compatibility and the existing licence.
