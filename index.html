05 / METHOD

Interpretation & limitations

Weighted linguistic quality

Meaning 40%, grammar 20%, academic register 20%, pedagogical clarity 20%. Each cue receives a human score from 0 to 5. Scores are normalised to 100.

Reading pace

Visible Unicode grapheme clusters divided by actual cue duration. Whitespace is normalised. This is a configurable screening metric, not proof of learner readability.

Decision policy

Only fully reviewed candidates meeting every gate qualify. Shortlist order is quality, then pacing compliance, then candidate ID. A pass supports further validation, not automatic deployment.

Evidence limitations

The default data is fictional. Import actual reviewed outputs for a real evaluation. Validate age-group comprehension, contextual fidelity, latency, and operational risk before adoption.
